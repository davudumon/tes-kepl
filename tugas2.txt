Lanjutkan repository evolusi-pl-NIM. Buat workflow empat tahap:
build → test → staging → production. Build dan test berjalan
dengan lancar. Deploy belum ke server, cukup ditulis sebagai echo.

LANGKAH
1. Ubah proyek jadi aplikasi Laravel sederhana (boleh CRUD satu
   tabel). Pastikan php artisan test jalan di laptop.

2. Tulis workflow empat job, dirangkai dengan needs:.
   - build: pasang dependensi dengan composer install
   - test: jalankan php artisan test
   - staging: echo saja
   - production: echo langkah deploy (lihat langkah 4)

3. Jaga job production. Syaratnya:
   - production hanya jalan dari branch main, pakai environment
     production dengan required reviewer;
   - push ke branch fitur tetap menjalankan build dan test.

4. Di job production, tulis 7 langkah deploy.sh (slide 6) sebagai
   echo, urut. Simpan juga deploy.sh di repo, dengan set -e.

5. Buktikan:
   - push ke branch fitur → production skipped;
   - gagalkan satu test → pipeline berhenti merah. Lalu perbaiki.
